## Итог реализации

Литературный текст отсутствует в DOM до выбора; выбор не переносится ссылкой и сбрасывается при навигации/локали. Шесть новых E2E защищают прямые ссылки, Next/Back/reload, язык, получателя и источники. Научный опыт остаётся доступен сразу.

Аудит сопровождения: production 4545→4521 физических строк, runtime dependencies 8→7, package records 96→92. Сохраняются i18next, ODEX, d3-geo, gl-matrix; удалены неиспользуемая React-обёртка переводов и 10 мёртвых ключей. Миграция App/CSS/router/solver без доказанной необходимости отложена. Подробности и метрика подсчёта — [maintenance-cost](../research/maintenance-cost.md).

## Проверка

[RAPID](../acceptance/rapid-decision.md) ссылается на независимые science/UX/teaching-отчёты. Финальный bundle `index-7oaePJm_.js`, SHA-256 `507765b09b26dd6051c424b2fe9a8125d9e5356b1a61c92a2936679662d34784`. Строгий TypeScript, build, **53 unit**, **33 E2E за 33,2 с**, audit 0. До очистки один Pause-сценарий дал 32/33; без изменения кода 5/5 отдельных повторов и 33/33 полный повтор прошли. Причина не установлена и записана в release evidence.

Код проверен RU/ZH на desktop/mobile Chromium и клавиатурой. Нет выдуманных интервью, физического iOS/Android/VoiceOver и доказательства учебного эффекта. Эти продолжения остаются отдельными карточками. #12 не закрывается сокращением его критерия: полная планетарная сцена действительно не реализована.

## Выпуск

Все изменения собираются в один review PR, затем принимаются в main. После CI — тег v1.0.0, готовый статический архив и контрольная сумма, публикация через GitHub Actions Pages, smoke живого адреса. Рабочие ветки удаляются лишь после проверки, что их коммиты доступны из main. Точный PR/merge/deploy записаны в итоговом решении и GitHub Release.

Ретроспектива: проверка количества строк сама по себе не обнаружила бы двойной слой переводов. Теперь release review требует карту обязанностей, импортов и полной стоимости замены, а не обязательную новую библиотеку или искусственное сокращение LOC.
