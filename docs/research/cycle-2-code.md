## C2-CODE-01 — P1: вкладки теряют уже пройденные уроки

**Источник:** `src/App.tsx:54,100–105`, `src/state/session.ts:96–113`.

Две вкладки читают прогресс один раз при загрузке. Сохранение заменяет весь массив снимком вкладки. Обработчика `storage` и объединения с текущим сохранённым состоянием нет.

**Воспроизведение:**

1. Очистить `kontur.progress.v1`; открыть начальный урок в вкладке A и `?lesson=1` во вкладке B.
2. В A выбрать правильный ответ и проверить вывод. Хранилище: `["straight-path"]`.
3. В B выбрать правильный ответ и проверить вывод. Хранилище: `["right-angles"]`.
4. Перезагрузить A: отображается «1 из 6 пройдено»; ранее завершённый первый урок потерян.

**Дополнительный дефект той же границы:** `readProgress` принимает любые строковые значения и дубликаты. Повреждённый/старый массив может дать ложное количество завершённых уроков больше шести. Это не вопрос доверия к серверу — данные браузера меняют расширения, старые версии и пользовательские инструменты.

**Минимальное исправление:** единая нормализация через список актуальных ID; удаление дубликатов; при обычном завершении слияние с последним нормализованным состоянием localStorage и возврат сохранённого результата; событие `storage` обновляет соседние вкладки. Явный сброс должен удалять прогресс, а не проходить через merge. Проверить работу при недоступном хранилище.

**Приёмка:** два разных урока, завершённые в двух вкладках, остаются завершёнными после перезагрузки обеих; неизвестные ID и дубликаты не увеличивают счётчик; явный сброс синхронизирует вкладки.

## C2-CODE-02 — P2: отказ копирования скрыт в свободной лаборатории

**Источник:** `src/App.tsx:87–98,462–464`.

Ошибку clipboard сохраняют в `feedback`, который отрисован только в форме ответа внутри маршрута. В свободной лаборатории и на странице оснований нет ни сообщения, ни ручного поля ссылки. В маршруте эта же ошибка загрязняет канал ответа на учебный вопрос.

**Воспроизведение:** открыть `?view=lab`, в отдельном browser probe заменить `navigator.clipboard.writeText` на отклонённый Promise и нажать «Поделиться опытом». Число видимых элементов с текстом «Ссылка находится в адресной строке браузера. Её можно скопировать вручную.» равно `0`. Повторить на `view=library`.

**Минимальное исправление:** отдельный статус/панель share рядом с управляющей кнопкой, доступный на всех страницах; селектируемое поле актуального URL и понятная инструкция при отказе clipboard. Не использовать состояние ответа quiz.

**Приёмка:** на всех трёх представлениях при успешном копировании объявлен успех; при отказе виден ручной URL и инструкция; ответ/оценка вопроса не меняются.

## C2-CODE-03 — P2: бренд сбрасывает выбранный китайский язык

**Источник:** `src/App.tsx:158`, `src/state/session.ts:47`.

Ссылка бренда содержит `href="?"`. После полной навигации исчезает `lang=zh-CN`, а отсутствие языка означает русский. Не сохраняется предпочтение пользователя при стандартном действии «домой».

**Воспроизведение:** открыть `?lang=zh-CN`, нажать бренд «界线». До клика `html[lang]` равно `zh-CN`; после — `ru`, параметр `lang` отсутствует.

**Минимальное исправление:** переход на начало через явное сохранение текущей локали; сохранить возможность обычного открытия ссылки в новой вкладке. Если бренд сбрасывает параметры опыта, этот выбор должен быть явным и не сбрасывать язык/прогресс.

**Приёмка:** действие бренда из каждой страницы возвращает начало маршрута на выбранном языке; новая вкладка по ссылке тоже имеет эту локаль.

## C2-CODE-04 — P2: Back уводит из приложения вместо предыдущего раздела

**Источник:** `src/App.tsx:61–67`.

Каждое изменение состояния, включая смену раздела и урока, выполняет `history.replaceState`. Обработчик popstate присутствует, но приложение не создаёт записей для собственных значимых переходов.

**Воспроизведение:** в новой вкладке открыть `about:blank`, затем приложение; нажать «Лаборатория», затем «Основания». Длина history до/после этих переходов остаётся `2`. Нажать Back: адрес становится `about:blank`, хотя предыдущим разделом была лаборатория.

**Минимальное исправление:** разделить значимые переходы (раздел/урок — push) и частые изменения параметров/кадров (replace); popstate восстанавливает состояние без создания дополнительной записи. Не добавлять запись истории на каждый кадр анимации или изменение range.

**Приёмка:** Back/Forward проходит разделы и уроки; смена ползунка и воспроизведение не создают сотни записей; URL и активный вид согласованы.

## Чего ревизия не утверждает

В прочитанной конфигурации deploy выполняется вручную, а CI проверяет тот же production build; нового воспроизводимого блокера в workflow не найдено. Численный адаптер ODEX имеет явные защитные границы, но чтение кода не подтверждает траектории на всех временах. Эти вопросы остаются в независимой научной ревизии. Нет необходимости расширять собственный численный движок ради исправлений выше.

По [issue #16](https://github.com/mmkolpakov/Geometry-System/issues/16) слой сохранения изменён: известные уникальные ID, слияние последнего сохранённого состояния с входом вызывающей вкладки, отдельный `clearProgress`, экспорт общего `PROGRESS_KEY`. Проверка `vitest run src/state/session.test.ts`: **10 passed**, включая 4 новых сценария валидности, двух последовательных stale-writer сохранений, явного сброса и недоступного хранилища. `tsc --noEmit` прошёл.

Это ещё не приёмка UI: компонент приложения должен читать возвращаемое значение `saveProgress` и реагировать на `storage`. LocalStorage не предоставляет compare-and-swap; данный минимальный контракт закрывает воспроизведённое последовательное перезаписывание и не заявляет атомарность одновременных операций нескольких процессов.
