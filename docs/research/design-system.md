# Design requirements mapped to evidence

Reviewed 14 November 2026. This is a decision record for the web product, not a claim of Apple certification or adoption of Microsoft's entire component system. Native points and web CSS pixels are different units. The criteria below distinguish external guidance, product decisions and checks still to complete.

## Source-to-decision matrix

## Measured baseline before this change

Read-only browser inspection of the implemented Russian three-body laboratory, from the current local Vite app before the Chinese/typography revision:

| Element |1440px viewport|390px viewport|Decision gap |
| --- | --- | --- | --- |
| Top navigation |42px high,13px text|38px high,11px text|Below adopted44px target; text too small for the adopted UI role. |
| Share icon/button |42px high|34×36px|Increase the icon-only click area, not just the icon artwork. |
| Formula mode |36px high,10px text|36px high,11px text|Increase target and use UI typography. |
| Playback buttons |38px high|40px high|Use44px minimum. |
| Timeline range |30px high|30px high|Increase native range element's hit box; visual track may stay thin. |
| Comparison labels |36px high,11px text|36px high,10px text|Entire associated label should be44px high with14px text. |
| Disclosure summary |34px high|34px high|Use44px target. |
| Lab explanation |13px|12px|Reading role16px; retain unitless line-height. |
| Model caveat |11px|10px|Supporting text14px; this carries important limits, not decorative metadata. |
| Metric label/caption |10px|9px|Caption floor12px; allow card growth rather than shrinking text. |

At320px the normal layout had no horizontal page overflow, but this was achieved partly by very small text. Applying the WCAG text-spacing override produced329px of page width in a320px viewport, with the top bar overflowing. Applying a200% root font size left `.lab-note` at12px because the authored values are absolute pixels. These observations motivate relative tokens and flexible controls. They are **not** a completed accessibility conformance audit: the spacing failure must be reproduced after the changes, and real browser zoom is distinct from setting root font size.

## Surgical implementation scope

1. Replace repeated font-size overrides at the end of `src/styles.css` with a short semantic token layer. Preserve the brand colours and component hierarchy; body/UI/caption roles have one size regardless of viewport.
2. Set minimum44px hit boxes on `.topbar nav button`, `.share-button`, `.level-button`, `.segmented button`, `.playback-controls button`, `.text-button`, `.comparison-toggle`, native ranges and `.formula-card summary`. Keep multiline button labels.
3. Give the topbar flexible rows, prevent the brand/locale/share row from overflowing at320px, and let navigation wrap when user text settings require it. Do not hide translated navigation text.
4. Stack metric cards at narrow widths or use auto-fit with sensible minimums. Do not force scientific values to squeeze into three narrow columns. SVG text is supplemental; numerical values remain readable outside the image.
5. Add a Chinese language rule for fonts, line-break behaviour and tracking. The root i18n implementation must translate all visible labels, SVG `<title>/<desc>`, tooltips, validation/error messages, source summaries and accessibility names; translating just navigation is incomplete.
6. Re-run visual/keyboard/contrast checks in both languages. Test320px reflow and spacing before recording acceptance. Distinguish automated evidence from future native Chinese reader and screen-reader validation.

## Evidence limits

Official guidance was retrieved on14 November2026; Apple HIG and Fluent are living documentation, not versioned “2026 certification” checklists. The design decisions above apply their current web-relevant guidance without claiming to reproduce either operating system. Chinese editorial fluency and comprehension by schoolchildren/research staff still require participant review; these cannot be established by screenshots, unit tests or passing axe scans alone.
