## Что считалось

Единица — **физическая строка** UTF-8-файла, включая пустые строки, комментарии, JSX и длинный текст. Это не logical SLOC: одна строка CSS может содержать десятки деклараций. Отдельно посчитаны непустые строки, файлы и байты. Включены tracked и ещё не закоммиченные, не игнорируемые файлы; исключены `.git`, `node_modules`, `dist`, временные test-results. Поэтому весь репозиторий нельзя сравнивать с размером исполняемого кода.

Повторить инвентаризацию без новой зависимости:

```sh
git ls-files --cached --others --exclude-standard -z -- src tests scripts .github | sort -zu | xargs -0 wc -l
wc -l src/App.tsx src/styles.css src/i18n.tsx src/state/session.ts
npm ls --depth=0
```

## Hotspots и решения

Все SP ниже — независимые предварительные оценки агента, не часы и не командный консенсус. Не следует суммировать альтернативные миграции в обязательный backlog.

| Область | Решение и основание | Полная стоимость / проверка |
| --- | --- | --- |
| `App.tsx`, 825 строк | **Отложить перестройку.** В одном файле shell, hero SVG, урок/quiz, share fallback, URL/history/progress effects. Позже выделить 2–3 завершённых компонента и один контроллер сессии; это снижает поверхность ревью, но может увеличить суммарные строки | 3 SP: сохранить focus, Next/Back, same-lesson history, reset и consent. Уже проверенные переходы важнее ограничения «не больше N строк в файле». [React рекомендует выделять содержательную повторно используемую логику в custom Hooks](https://react.dev/learn/reusing-logic-with-custom-hooks), а не создавать hook для каждой строки |
| CSS, 1668 строк | **Оставить CSS; отложить упорядочение каскада, 5 SP.** AST через уже установленный PostCSS: 498 правил, 1197 деклараций, 402 уникальных контекста selector + at-rule, из них 80 встречаются повторно. `.topbar nav button` и `.segmented button` внутри `max-width:760px` встречаются по 4 раза. Повторение не доказывает ненужность | Объединять по компоненту/брейкпоинту с сохранением computed style в RU/ZH при 320/390/768/1440, focus и reduced motion. Простой перенос правил меняет [каскад и порядок победивших объявлений](https://developer.mozilla.org/en-US/docs/Web/CSS/CSS_cascade/Cascade). Tailwind/Fluent/MUI не удалят локальные layout/typography требования; полной миграции без пользовательской причины нет |
| i18n, 103 строки | **Убрать лишний bridge, оставить i18next.** В коде нет `useTranslation`, `Trans`, `withTranslation` или иных потребителей контекста react-i18next. Приложение уже использует свой `LocaleContext` и [фиксированный `getFixedT`](https://www.i18next.com/overview/api#getfixedt). Provider и plugin создают второй слой без задачи | 3 SP на удаление `react-i18next`/plugin/provider, обновление lock/notices, проверку fallback, первого кадра RU→ZH, чисел и обеих локалей. [Provider нужен потребителям его контекста](https://react.i18next.com/latest/i18nextprovider); сохранение готового i18next предпочтительнее нового собственного переводчика |
| Переводы | **Удалить подтверждённые мёртвые ключи, 1 SP.** Предварительный поиск по вхождению текста дал 9 ключей `ui.zh.ts`, а проверка исполнителя по литералам вызовов подтвердила 10: короткий ключ «из» случайно входил в другие слова. `labs.zh.ts` — 0. В том числе старое «Опыт пройден» и прежние спойлерные фразы. `languageFrom` вызывается только своими тестами, URL разбирается отдельно | Исключить динамические ключи перед удалением. Не удалять весь тестовый файл: останутся реальные проверки `translate`/чисел. Полный переход на короткие key-ID — 5–8 SP, затрагивает контент/скриншоты и оправдан при редакторском процессе или новых локалях, не ради минификации |
| URL, history и progress | **Оставить Web APIs.** `URLSearchParams`, History API, localStorage и 143 строки контракта — достаточны для 3 разделов. [React Router useSearchParams](https://reactrouter.com/api/hooks/useSearchParams) управляет URL-навигацией, но не заменяет валидацию научных параметров, семантику merge/reset и политику consent | Router/Zustand/XState/Zod сейчас не дают подтверждённой экономии. Router migration 5 SP с сохранением старых ссылок, Back, focus, кадров и consent; отложить до маршрутов/вложенных страниц. Нативный [URLSearchParams](https://developer.mozilla.org/en-US/docs/Web/API/URLSearchParams) уже делает стандартную сериализацию |
| UI controls | **Оставить native controls и React/SVG.** Кнопки, range, select, table и details уже предоставляют базовую семантику. `StoryDisclosure` обязан не монтировать сюжет; простое CSS-скрытие или обычный закрытый details не эквивалентны этому контракту | Не вводить UI framework, chart library или собственную компонентную платформу ради шести опытов. | Tests, 1201 строк | **Оставить Vitest/Playwright/axe.** Эталонные тесты защищают науку и сложные переходы. Есть повторение проверки overflow/axe и runtime-error hook только в `flows.spec.ts` | 2 SP: использовать стандартную [Playwright fixture](https://playwright.dev/docs/test-fixtures) для runtime errors и короткие общие helpers. Не делать новый DSL. Параметризовать RU/ZH только при одинаковом сценарии; не удалять независимые численные эталоны ради LOC |
| Docs/артефакты | **Сократить дублирование, не доказательства.** `issues.json` 119 237 байт и backlog — снимки, GitHub остаётся канонической доской; длинные JSON и PNG не раздувают runtime | 2 SP: единый индекс принятых решений/текущей версии, исторические циклы остаются датированными; CI хранит полный transient report, репозиторий — выбранные evidence. Не добавлять новую копию статусов или raw JSON в каждый аудит. Лицензии/notices не удалять |

## Готовые научные части: оставить

- **d3-geo** уже выполняет сферическое расстояние, интерполяцию и площадь. Конверсия градусов/радиан, ориентация полигона, метрика и округление остаются обязанностью приложения при любой библиотеке. [Официальный API](https://d3js.org/d3-geo/math). Замена на JSXGraph имеет смысл для свободного построения фигур; сейчас добавит board lifecycle, другой renderer и повторную доступностную/научную приёмку: 8–13 SP, **отложить**.
- **ODEX** уже владеет адаптивным интегратором; 136 строк приложения задают ньютоновскую правую часть, начальные условия, guardrails и диагностику. Deep import сейчас совпадает с `main` установленного пакета и сам по себе не является доказанным багом. RC, опубликованный API и обновления требуют отдельного gate. [ODEX](https://github.com/littleredcomputer/odex-js), [REBOUND/WASM пример](https://rebound.hanno-rein.de/c_examples/simplest/). Оставить pin; процедура обновления с clean install, DOP853, инвариантами и браузерным прогоном — 2 SP. Другой JS solver 5–8 SP, WASM bridge 13–21 SP без подтверждённой необходимости — **отложить**.
- **gl-matrix** выполняет поворот в 106-строчном компоненте проекции. Не писать свой матричный движок и не выдавать удаление зависимости за научную оптимизацию. Добавить отсутствующее решение по этой зависимости в существующий `dependencies.md` вместе с float32-допуском и контрольными 0°/45°/90°: 2 SP. **Оставить**.
- **observer 15 строк, viewport 27 строк, Poincaré adapter** выражают особенности продукта. Complex.js заменит две операции комплексной арифметики, а не гиперболическую геометрию. Астрономический API не выберет вместо продукта физические допущения датчика. **Оставить**, не расширять горизонт/входы без соответствующих инвариантов и sweep-проверки.

Независимый второй просмотр научных зависимостей выполнил агент `education_sources`: вывод о сохранении d3-geo/ODEX/gl-matrix совпал. Его оценки альтернатив выше сохранены как диапазоны неопределённости, не обещанный план.
